## Primary category

## Action description

Cyber Resilience Act readiness checks for GitHub repositories.

## Short pitch

Detect repository-level product-security evidence that supports Cyber
Resilience Act readiness: security policy, SBOM availability, Dependency Graph,
dependency monitoring, Code Scanning and operational ownership. Private by
default; optional sanitized sync to ForgeVault Pro.

## Trust line

Runs inside GitHub Actions. No source code is uploaded to ForgeVault unless the
workflow explicitly enables the optional SaaS sync.

## Discoverability terms

policy, dependency monitoring, incident readiness, CRA Article 14, software
manufacturer, security evidence.
