# Security policy

ForgeVault CRA Readiness runs repository checks inside the GitHub Actions
runner. It does not upload source code or raw dependency data by default.

## Supported versions

The moving `v1` major tag receives compatible fixes. Pin a specific release tag
or commit when your organisation requires immutable workflow inputs.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** or security advisory
workflow for this repository. Do not open a public issue with secrets, private
repository data or unreleased vulnerability details. If private reporting is
not available, contact the repository owner privately through GitHub and share
only the minimum reproduction details required for triage.
